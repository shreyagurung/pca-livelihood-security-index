# Outputs

This directory contains the files generated by the PCA-based Livelihood Security Index analysis.

The outputs are generated automatically by:

    R/LSI_PCA_Analysis.R

Study-specific analytical outputs may be excluded from the public repository where they contain unpublished research results.

## Generated CSV Files

### 01_Indicator_Z_Values.csv

Contains the Z-standardized values of all livelihood indicators used as inputs to PCA.

The original normalized 0–1 values are not replaced by these values. Z-standardization is performed specifically for the PCA stage.

---

### 02_Eigenvalues_All_PCs.csv

Contains the eigenvalue and explained-variance information for every principal component generated by the PCA.

Variables include:

- Principal component
- Eigenvalue
- Proportion of variance explained
- Percentage of variance explained
- Cumulative variance
- Cumulative percentage of variance

---

### 03_Eigenvalues_Retained_PCs_Table_5_10.csv

Contains the eigenvalue and explained-variance information for the principal components retained using the Kaiser criterion.

The retention criterion is:

    Eigenvalue > 1

---

### 04_PCA_Loadings_All_PCs.csv

Contains the PCA loading of every indicator on every principal component generated by the analysis.

Loadings represent the relationship between each indicator and each component.

---

### 05_PCA_Loadings_Retained_PCs_Table_5_11.csv

Contains the PCA loadings only for the principal components retained under the Kaiser criterion.

These loadings are subsequently used to derive the indicator weights.

---

### 06_PCA_Derived_Indicator_Weights.csv

Contains the final indicator weights derived from the retained PCA loadings and the proportion of variance explained by the retained components.

The file reports:

- Indicator name
- Weight percentage
- Weight proportion

The weight proportions sum to 1.

---

### 07_Panchayat_Wise_PCA_Scores.csv

Contains the PCA scores for each observation across all principal components generated by the analysis.

These scores represent the position of each observation along the principal component dimensions.

---

### 08_Block_Wise_PCA_Scores.csv

Contains higher-level PCA scores calculated as the mean PCA score of observations belonging to the same higher-level grouping variable.

The grouping variable is taken from the first identifier column in the input dataset.

---

### 09_Livelihood_Security_Index_Panchayat_Wise.csv

Contains the observation-level Livelihood Security Index.

The LSI is calculated using:

    LSI_j = sum_i P_ij W_i

where:

- `P_ij` is the original normalized indicator value
- `W_i` is the PCA-derived indicator weight

The file also contains the corresponding LSI classification.

---

### 10_LSI_Class_Counts.csv

Contains the number and percentage of observations falling into each LSI classification:

- Low
- Moderate
- High

The classification boundaries are calculated from the overall LSI distribution using:

    Lower boundary = Mean - 0.5 × SD

    Upper boundary = Mean + 0.5 × SD

---

### 11_Livelihood_Security_Index_Block_Wise.csv

Contains higher-level LSI summaries.

Reported statistics include:

- Number of observations
- Mean LSI
- Standard deviation
- Minimum LSI
- Maximum LSI

The higher-level LSI is based on the mean observation-level LSI within each group.

---

## Correlation Analysis Outputs

### Pearson_Correlation_Matrix.csv

Contains the Pearson correlation coefficients between all normalized livelihood indicators.

Correlation coefficients range from -1 to +1.

---

### Pearson_Correlation_P_Values.csv

Contains the corresponding p-values for the Pearson correlation coefficients.

Significance is interpreted using:

    *** p < .001
    **  p < .01
    *   p < .05
    ns  not significant

---

### Pearson_Correlation_Matrix_LSI.png

A high-resolution lower-triangle heatmap of the Pearson correlation matrix.

The heatmap displays:

- Pearson correlation coefficients
- Statistical significance notation

The image is generated at high resolution for potential use in research reporting and publication workflows.

---

## Consolidated Excel Workbook

### LSI_PCA_COMPLETE_RESULTS.xlsx

A consolidated Excel workbook containing the principal analytical outputs.

The workbook contains the following sheets:

1. Indicator Z Values
2. Eigenvalues All PCs
3. Table 5-10 Eigenvalues
4. PCA Loadings All PCs
5. Table 5-11 Loadings
6. PCA Indicator Weights
7. Panchayat PCA Scores
8. Block PCA Scores
9. Panchayat LSI
10. LSI Class Counts
11. Block LSI

The workbook provides a convenient consolidated format for reviewing the outputs generated by the analysis.

## Output Reproducibility

All outputs listed above are generated programmatically by:

    R/LSI_PCA_Analysis.R

They should not be manually edited as part of the analytical workflow.

If the input dataset or methodology changes, the analysis should be rerun so that the outputs remain consistent with the underlying data and code.
